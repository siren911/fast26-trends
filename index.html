🤖 AI/LLM이 스토리지를 재정의

FAST '26에서 가장 큰 비중(9편)을 차지한 카테고리로, LLM 추론·학습 파이프라인 전반에서 스토리지가 핵심 병목으로 부상했음을 보여준다. 특히 KV 캐시가 GPU 메모리를 압도하면서 SSD를 KV 캐시 확장 계층으로 활용하는 연구가 3편 동시 등장했다. 체크포인트 최적화, 모델 로딩 가속, AI 워크로드 전용 클라우드 스토리지까지 — AI 인프라의 모든 단계에서 스토리지 혁신이 요구되고 있다.

삼성전자 메모리 시사점

삼성전자 메모리 사업부에 가장 직접적인 영향을 미치는 트렌드. SSD가 KV 캐시 확장 계층으로 활용되면서 AI PC용 고대역폭·저지연 NVMe SSD 수요가 급증할 전망. 체크포인트/모델 로딩용 고내구성 엔터프라이즈 SSD(PM9A3, PM9D3 등)의 시장 확대도 예상된다. Samsung Semiconductor의 Seneca 논문은 ML 데이터 파이프라인 최적화에 직접 기여하여 삼성 SSD 생태계 강화에 활용 가능하다.

SolidAttention

SolidAttention: Low-Latency SSD-based Serving on Memory-Constrained PCs
Xinrui Zheng, Dongliang Wei, Jianxiang Gao, Yixin Song, Zeyu Mi, Haibo Chen — Shanghai Jiao Tong University
AI PC(AIPC)에서 대규모 언어모델(LLM)을 로컬 추론할 때, KV 캐시가 GPU/시스템 메모리를 압도하는 문제를 해결한다. 128K 토큰 컨텍스트에서 KV 캐시는 수십 GB에 달하지만, 일반 PC의 메모리는 16~32GB에 불과하다. SolidAttention은 동적 어텐션 희소성(sparse attention) 알고리즘과 SSD 기반 스토리지 관리를 공동 설계하여, KV 쌍을 SSD에 오프로드하면서도 추론 정확도를 유지한다. 핵심 기법은 세 가지다: (1) 여러 KV 쌍을 굵은 입도(coarse-grained) 블록으로 통합하여 SSD 대역폭을 최대 활용, (2) 희소 어텐션의 시간적 지역성(temporal locality)을 이용한 투기적 프리페치(speculative prefetching), (3) 연산과 I/O의 세밀한 오케스트레이션으로 동기화 지점을 재사용하여 SSD 유발 블로킹 지연을 최소화한다.
문제

AIPC의 제한된 메모리(16~32GB)에서 LLM의 KV 캐시(128K 토큰 시 수십 GB)를 수용할 수 없음

핵심 통찰

어텐션의 동적 희소성을 활용하면 대부분의 KV 쌍은 SSD에 두고 필요한 것만 메모리에 로드 가능

SSD 대역폭 최적화 블록 통합 + 투기적 프리페치 + 연산-I/O 파이프라이닝

CacheSlide

CacheSlide: Unlocking Cross Position-Aware KV Cache Reuse for Accelerating LLM Serving
Yang Liu, Yunfei Gu, Liqiang Zhang, Chentao Wu, Guangtao Xue, Jie Li, Minyi Guo, Junhao Hu, Jie Meng — Shanghai Jiao Tong University, Huawei Cloud
LLM 에이전트 애플리케이션에서 복잡한 프롬프트 구조(불변 시스템 프롬프트 + 동적 사용자 입력)의 KV 캐시 재사용을 최적화한다. 기존의 위치 의존(PDC)과 위치 독립(PIC) 캐싱은 에이전트 워크플로의 '상대 위치 의존(RPDC)' 패턴을 처리하지 못한다. RPDC 패턴에서는 재사용 가능한 세그먼트가 절대 위치는 달라지지만 상대적 순서는 유지된다. CacheSlide는 Chunked Contextual Position Encoding으로 고정 세그먼트의 위치 인코딩 유사성을 강화하고, Weighted Correction Attention으로 최소한의 토큰만 재연산하며, 계층별·스필 인식 KV 캐시 최적화를 적용한다. vLLM 기반으로 구현되어 실제 서빙 환경에 배포 가능하다.
문제

에이전트 기반 LLM 서빙에서 위치 인코딩 불일치(PMKD)로 인한 KV 캐시 재사용 불가

핵심 통찰

고정 세그먼트는 절대 위치가 바뀌어도 상대 위치가 유지되므로, 위치 인코딩을 보정하면 재사용 가능

기술 접근

RPDC 패턴 인식 + Chunked Contextual Position Encoding + Weighted Correction Attention

Bidaw

Bidaw: Enhancing Key-Value Caching for Interactive LLM Serving via Bidirectional Computation–Storage Awareness
Shipeng Hu, Guangyan Zhang, Yuqi Zhou, Yaya Wei, Ziyan Zhong, Jike Chen — Tsinghua University, China Telecom
대화형 LLM 서빙에서 다중 라운드 대화의 KV 텐서를 호스트 메모리와 SSD의 2계층 스토리지에 캐싱할 때, 컴퓨트 엔진과 스토리지 간의 조율 부족으로 지연이 3.8배 증가하고 처리량이 2배 감소하는 문제를 해결한다. Bidaw는 양방향 인식(bidirectional awareness)을 도입한다: (1) 컴퓨트 방향 — KV 로딩 지연을 인식하여 요청을 스토리지 계층별로 분리·재정렬하여 블로킹 최소화, (2) 스토리지 방향 — LLM 생성 응답을 분석하여 사용자 접근 패턴을 예측하고 KV 축출(eviction) 정책에 반영. 추가로, 스토리지 효율적인 히스토리 텐서만 선택적으로 캐싱하여 저장 공간 대비 연산 절감 효과를 극대화한다.
문제

핵심 통찰

LLM의 응답 패턴을 분석하면 사용자의 다음 접근을 예측할 수 있어 캐시 적중률 향상 가능

PPC/MAIO

Accelerating Model Loading in LLM Inference by Programmable Page Cache
Yubo Liu, Hongbo Li, Xiaojia Huang, Yongfeng Wang, Hanjun Guo, Hui Chen, Yuxin Ren, Ning Jia — Huawei Technologies
LLM 추론 시작 시 모델 로딩(예: 79GB 모델)이 핵심 병목이 되는 문제를 해결한다. 기존 최적화들은 성능을 높이려면 호환성을 희생해야 했다. PPC(Programmable Page Cache)는 커널 파일시스템의 캐시 정책을 사용자가 비침습적·유연·경량으로 커스터마이징할 수 있는 프레임워크이며, MAIO는 PPC 위에 구현된 모델 로딩 최적화 캐시 정책이다. MAIO의 핵심은 I/O 템플릿 기반 메커니즘으로, SSD 대역폭을 완전히 활용하면서 XPU(GPU/NPU) 친화성과 데이터 지역성을 고려한 프리페치와 축출을 수행한다. 모델을 한 번 로딩하면 I/O 패턴을 템플릿으로 기록하고, 이후 로딩 시 템플릿에 따라 최적 프리페치를 수행한다.
문제

79GB LLM 모델 로딩이 추론 시작의 핵심 병목 — 기존 최적화는 호환성을 희생

핵심 통찰

모델 로딩의 I/O 패턴은 반복적이므로 한 번 기록한 템플릿으로 최적 프리페치 가능

GCR

GPU Checkpoint/Restore Made Fast and Lightweight
Shaoxun Zeng, Tingxu Ren, Jiwu Shu, Youyou Lu — Tsinghua University
GPU 체크포인트/복원(C/R)은 탄력 스케일링, 태스크 전환, 내결함성 등 현대 GPU 워크로드의 핵심 기능이다. 그러나 기존 방식은 낮은 C/R 지연과 낮은 실행 오버헤드를 동시에 달성하지 못하고, 증분 체크포인팅도 효율적으로 지원하지 못한다. GCR은 제어/데이터 분리(control/data separation)를 통한 하이브리드 C/R 방식으로 낮은 지연과 무시할 만한 실행 오버헤드를 동시에 달성한다. 증분 체크포인팅을 위해 CPU에서 '그림자 실행(shadow execution)'을 수행하여 더티 버퍼를 식별하고, '더티 템플릿(dirty template)'으로 명령어 수준의 세밀한 식별을 지원한다. NVIDIA 공식 솔루션(cuda-ckpt) 대비 체크포인팅 72.1%, 복원 54.2% 지연 감소를 달성한다.
문제

핵심 통찰

제어 경로와 데이터 경로를 분리하고, CPU 그림자 실행으로 더티 데이터를 경량 식별

기술 접근

AdaCheck

TEE(Trusted Execution Environment)는 사용자가 민감한 애플리케이션을 사적 메모리 영역에서 실행할 수 있게 한다. SGX-PFS는 TEE용 최신 보안 스토리지 솔루션으로 데이터의 기밀성, 무결성, 신선도, 일관성(CIFC)을 보장하지만, Merkle Hash Tree를 사용한 인-플레이스 영속화로 인해 I/O 성능이 열악하여 실용성이 제한된다. MlsDisk는 아웃-오브-플레이스 로깅을 채택한 보안 가상 디스크로, 효율적인 TEE 신뢰 블록 스토리지를 제공한다. 로그 구조 스토리지의 인덱싱과 GC의 복잡성이 보안 보장을 어렵게 하는 도전에 대해, 4개 레이어의 추상화로 인덱싱과 GC를 분해하여 CIFC 속성에 대한 추론을 용이하게 한다. SGX-PFS 대비 마이크로벤치마크에서 7.3~21.1배, 트레이스 기반 워크로드에서 1.4~3.6배 성능 향상을 달성한다.
문제

핵심 통찰

TEE 보안은 삼성 SSD의 하드웨어 암호화(SED, TCG Opal) 기능과 시너지. MlsDisk의 보안 스토리지 계층과 삼성 SSD의 하드웨어 AES 암호화를 결합하면 엔드-투-엔드 보안 스토리지 솔루션 구현 가능. 기밀 컴퓨팅(Confidential Computing) 시장에서 삼성 SSD의 차별화 포인트.

CoFS

CoFS: A Filesystem for Fast Container Startup
Li Wang, Jinxu Du, Yang Yang, Qingbo Wu, Tao Liu, Haoze Wu — KylinSoft
컨테이너 환경에서 애플리케이션 실행이 산업의 주류 트렌드가 되었다. 컨테이너의 콜드 스타트는 이미지 다운로드와 이미지 언패킹이라는 시간 소모적 순차 과정을 포함하며, 높은 콜드 스타트 지연은 서버리스 컴퓨팅이나 버스트 요청 대응 시 응답성 SLA 위반을 유발할 수 있다. 최신 시스템은 온디맨드 이미지 풀링으로 가속하지만, 유저스페이스 I/O 중개 오버헤드, 유지보수성, 성능 변동 문제를 겪는다. CoFS는 확장 FUSE 기반의 빠른 컨테이너 시작을 위한 새로운 파일시스템이다. 핵심 통찰은 컨테이너 이미지는 한 번 빌드되고 컨테이너 관점에서 고정 읽기전용 파일시스템 트리라는 점이다. CoFS는 이미지 빌드 시 MPHF(Minimal Perfect Hash Function)를 구성하고 파일 메타데이터를 해시값으로 인덱싱된 밀집 배열에 저장한다. MPHF는 충돌 없고 공간 최적이므로 대부분의 경우 커널 스페이스에서 1회 이하 I/O로 lookup을 완료하여, FUSE의 비용이 높은 유저스페이스 lookup을 효과적으로 회피한다.
