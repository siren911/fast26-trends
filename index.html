🧠
AI/LLM 스토리지
스토리지가 AI 인프라의 핵심 병목으로 부상
LLM 추론 시 KV 캐시가 GPU 메모리를 압도하면서 SSD를 KV 캐시 확장 계층으로 활용하는 연구가 3편 동시 등장했습니다. AI 학습·배포 파이프라인 전반에서 스토리지 최적화가 핵심 이슈로 자리잡았으며, 체크포인트 최적화, 모델 로딩 가속, 학습 데이터 전처리까지 폭넓은 주제가 다뤄졌습니다.
삼성전자 메모리 사업 시사점
KV 캐시 오프로드는 고대역폭·저지연 SSD 수요를 직접 견인합니다. 삼성의 PCIe Gen5 NVMe SSD는 14GB/s 순차 읽기로 KV 캐시 프리페칭에 유리하며, SolidAttention의 coarse-grained block 접근 패턴에 최적화된 펌웨어 튜닝이 가능합니다.
Bidaw의 2-tier (메모리+SSD) KV 캐시 구조는 삼성 CXL 메모리 익스팬더(CMM-D)의 활용 시나리오와 직접 연결됩니다. CXL 메모리를 DRAM과 SSD 사이의 중간 캐시 계층으로 배치하면 지연시간을 추가 절감할 수 있습니다.
GPU 체크포인트(GCR)의 72.1% 지연 감소는 SSD 쓰기 대역폭에 의존합니다. 삼성 PM9D3/PM9E3 같은 데이터센터 SSD의 높은 순차 쓰기 대역폭이 체크포인트 성능의 핵심 요소입니다.
NAND 관점에서 KV 캐시 워크로드는 랜덤 읽기 비중이 높고 쓰기량이 제한적이므로, QLC NAND 기반 고용량 SSD도 적합할 수 있습니다. 이는 TCO 절감과 직결됩니다.
모델 로딩(MAIO)에서 SSD 대역폭 활용률이 핵심이므로, NVMe 멀티 큐/멀티 스트림을 적극 활용하는 펌웨어 최적화가 필요합니다.
논문 상세 분석 (9편)
SolidAttention: Low-Latency SSD-based Serving on Memory-Constrained PCs
KV 캐시
Xinrui Zheng 외, Shanghai Jiao Tong University
기술 요약
메모리 제한 PC(AIPC)에서 LLM 추론 시 KV 캐시를 SSD로 오프로드하는 추론 엔진입니다. 동적 attention sparsity 알고리즘과 SSD 스토리지 관리를 긴밀하게 co-design하여, KV 쌍을 coarse-grained 블록으로 통합하고 시간적 지역성을 활용한 투기적 프리페칭을 구현합니다.
핵심 기술
Coarse-grained KV 블록 통합, 시간적 지역성 기반 투기적 프리페칭, 연산-I/O 파인그레인 오케스트레이션, 동기화 포인트 재사용
설계 포인트
SSD 대역폭을 최대한 활용하기 위해 다수의 KV 쌍을 하나의 블록으로 묶어 순차 I/O로 전환하고, sparse attention 패턴의 시간적 지역성을 이용해 다음에 필요한 블록을 미리 프리페치합니다.
성능 결과
128K 토큰 컨텍스트에서 추론 속도 3.1배 향상, KV 캐시 메모리 사용량 98% 감소, 정확도 손실 없음
CacheSlide: Unlocking Cross Position-Aware KV Cache Reuse for Accelerating LLM Serving
KV 캐시
Yang Liu 외, Shanghai Jiao Tong University / Huawei Cloud
기술 요약
에이전트 기반 LLM 애플리케이션에서 프롬프트의 불변/동적 세그먼트를 효율적으로 관리하는 KV 캐시 시스템입니다. 기존 PDC/PIC 방식의 한계(위치 제약, PMKD 문제)를 해결하기 위해 Relative-Position-Dependent Caching(RPDC) 패턴을 식별합니다.
핵심 기술
Chunked Contextual Position Encoding, Weighted Correction Attention, 레이어별 KV 캐시 최적화, spill-aware 관리
설계 포인트
고정 세그먼트의 위치 인코딩 유사성을 높여 캐시 재사용률을 극대화하고, 최소한의 토큰만 재계산하여 새 KV와 캐시된 KV를 학습된 가중치로 결합합니다.
성능 결과
지연시간 3.11~4.3배 감소, 처리량 3.5~5.8배 향상

Accelerating Model Loading in LLM Inference by Programmable Page Cache
